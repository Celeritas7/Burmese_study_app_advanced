# Claude Code prompt — Word Tree in Study/Story mode

Paste everything below into Claude Code, run from the root of `Burmese_study_app_advanced/`.
The HTML file `Story Mode Word Tree.html` in this folder is the **visual + interaction reference** — recreate its behavior in the real app; do not ship the HTML.

---

## Task

Add a **Word Tree** view to the Study tab. When the learner opens it for the current word, show the **full hub forest** — every hub with its spokes — generated by the existing hub generator, rendered as top‑down org‑chart trees. Highlight the word currently being studied and auto‑scroll to its hub.

This must reuse the app's **existing** hub generator so the trees are identical to the Hub Explorer's "All Hubs" tab. Do not write a new grouping algorithm.

## Context — files that already exist

- `js/hubexplorer.js` — contains the private function `buildGroups(consonantsRaw, wordsRaw)` that returns `{ cons, hubs, fillers }`. Each hub is `{ id, word, meaning, consonantId, spokes: [{ word, meaning }] }`. This is the generator to reuse. It is currently module‑private (only the `HubExplorer` class is exported).
- `js/study.js` — `StudyTab` class. Renders the word card; `#btn-story` calls `showStoryModal(word)`. `word` objects are `{ burmese_word, english_meaning, ... }`. Already imports `toPronunciation` from the language‑utils module and `Modal` from `./modal.js`.
- `js/modal.js` — `Modal.show(htmlString, { borderColor, onClose })` injects a modal, wires any `[data-modal-close]` buttons, and **returns the box element**. `Modal.close()` removes it.
- `js/supabase.js` — `db.getWords()` and `db.getConsonants()` (both async).
- `css/styles.css` — design tokens in `:root`: `--bg #131F24`, `--surface #1A2C33`, `--border`, `--green #58CC02`, `--blue #1CB0F6`, `--yellow #FFC800`, `--purple #CE82FF`, `--text`, `--text-muted`, `--font`.

## Steps

1. **Export the generator.** At the bottom of `js/hubexplorer.js` add:
   ```js
   export { buildGroups };
   ```

2. **Import it in `js/study.js`:**
   ```js
   import { buildGroups } from './hubexplorer.js';
   ```

3. **Add a `showWordTreeModal(word)` method** to `StudyTab` (see the reference implementation in `IMPLEMENTATION.md` in this folder — it is copy‑ready). It must:
   - `await Promise.all([db.getConsonants(), db.getWords()])`, then `buildGroups(consonants, words)`.
   - Sort hubs by spoke count descending (matches the "All Hubs" tab).
   - Render each hub as an org‑chart tree: green hub node at top, connector lines, blue spoke nodes below. Use the pure‑CSS connector technique from the reference HTML.
   - Each node shows only the Burmese word by default. **Tapping a node reveals its pronunciation (`toPronunciation(word, { tones:false })`) and English meaning.** Tapping again hides them.
   - A chevron on the hub folds/unfolds that hub's spokes.
   - The node whose word === `word.burmese_word` gets the purple "studying" highlight + a "studying" pill, is auto‑expanded, and the forest scrolls to its card (`forest.scrollTop = card.offsetTop - 12` — **do not use scrollIntoView**).
   - Mount via `Modal.show(html, { borderColor: 'var(--green)' })` and attach one delegated `click` listener to the forest container.

4. **Wire it up.** Add a `🌳 Tree` button to the action row next to `#btn-story` and bind:
   ```js
   container.querySelector('#btn-tree').addEventListener('click', () => this.showWordTreeModal(word));
   ```

## Constraints / gotchas

- Spoke objects carry only `{ word, meaning }` — pronunciation is **computed** with `toPronunciation`, never read from a field.
- Scope all CSS with a `wt-` prefix to avoid collisions; the reference includes a `--border-light` fallback of `#2A3A42` in case it's not in `:root`.
- Match the app's existing dark theme and modal conventions exactly (see `showStoryModal` / `showHubModal` in `study.js` for the house style).
- Keep everything in vanilla JS / template strings — the app uses no framework or build step.

## Acceptance

- Opening the tree from any word shows all hubs as trees, sorted by spoke count.
- The studied word is visibly highlighted and its hub is scrolled into view on open.
- Tapping a node toggles pronunciation + meaning; the hub chevron folds/unfolds spokes.
- Trees match the Hub Explorer "All Hubs" output one‑to‑one.
