# Burmese song catalog — Phase 3

The Songs & Chants page links to YouTube; this repository does not download or host recordings or reproduce song lyrics.

Each `learningWords` value is a **topic or vocabulary prompt** based on the video's title, description, or theme. It is **not** a verified word-by-word transcript. Some videos are multi-song collections, a traditional dance performance, or Pali chants with Burmese subtitles. Those are labeled as such in the artist/source description. For Pali chants, the Burmese text is primarily useful as translation or explanation, not evidence that the recited text is conversational Burmese.
